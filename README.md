# Verified Talent Chain

## Requisitos

- Node.js 18 o superior (incluye npm)
- Git

## Instalación

```bash
git clone https://github.com/zagu5/VerifiedTalentChain.git
cd VerifiedTalentChain/frontend
npm install
```

## Cómo correrlo

```bash
npm run dev
```

Abre la dirección que muestra la terminal (normalmente http://localhost:5173).
